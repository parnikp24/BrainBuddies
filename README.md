# 🌸 Brain Buddies: An Interactive Guide to Your Feelings

> A cozy, youth-centric cognitive architecture simulation designed to make affective neuroscience accessible, transparent, and empathetic for children and teens.

✨ **Live Web Application:** https://github.io
📂 **Open Source Codebase:** https://github.com

---

## 🧸 About Brain Buddies
**Brain Buddies** is an interactive educational tool that translates complex emotional regulation frameworks into a warm, supportive visual experience. When users type out real-world dilemmas—like school anxiety, friendship arguments, or big exciting achievements—the application maps how that stimulus flows sequentially through four critical regions of the human brain: the **Thalamus**, the **Amygdala**, the **Hippocampus**, and the **Prefrontal Cortex**.

Instead of hiding behind a robotic developer interface, each brain module is animated as a supportive "buddy" that talks directly to the user in plain, comforting language, ending with actionable emotional regulation next steps.

## 🔬 Computational & Architectural Design
To prioritize absolute child data privacy and total scientific transparency, this application completely avoids non-deterministic, "black box" large language model APIs. Instead, it relies on a local, client-side, rule-based pipeline:

*   **Deterministic Lexical Gating:** The application tokenizes raw text strings on the browser canvas and screens them against an internal lookup map. It resolves input data arrays into 6 distinct cognitive frameworks:
    *   *Academic Evaluation* (School/Grades)
    *   *Zoophobic Arousal* (Animal Fears)
    *   *Peer Dynamics* (Friend Fights)
    *   *Familial Stress* (Family Dynamics)
    *   *Reward & Reinforcement* (Big Wins)
    *   *General Affective States* (Happy / Sad Fallbacks)
*   **Sequential Latency Emulation:** Processing loops use time-delayed clocks (~500ms to 1100ms) to mirror chronological biological signal propagation through brain pathways.
*   **Affective Metric Mapping:** Custom reactive meters calculate Worry, Happiness, and Working Memory Load using automated baseline mathematical jitter to reflect organic biometric fluctuations.
*   **Privacy-First Infrastructure:** Built using native JavaScript and Tailwind CSS via CDN. The application operates entirely inside the client browser, requiring no backend servers or credential tracking.

## 🌸 Meet the Buddies under the Hood
1.  **🚪 Thalamus (The Doorman):** Acts as the sensory gating layer. It parses text configurations and routes the payload down the line.
2.  **💗 Amygdala (The Alarm):** Evaluates rapid emotional salience, picking up threat tokens or excited arousal patterns instantly.
3.  **📔 Hippocampus (The Memory Keeper):** Runs pattern-completion loops across historical context modules to see if this feeling has happened before.
4.  **🌸 Prefrontal Cortex (The Wise Friend):** Executes top-down cognitive reappraisal, translating the emotional feedback loop into clear, calming, and practical guidance.
